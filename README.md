# Fourtune e-mail aláírás

- `index.html` – aláírás-készítő, élőben: https://ribsbenjo.github.io/fourtune-alairas/ – nyisd meg, írd át a nevet, szerepet, telefont és LinkedInt, majd **Aláírás másolása** és Cmd+V a levelező aláírás-mezőjébe.
- `fourtune-logo.svg` – a Fourtune logó vektorosan (bal oldalt a jel, jobbra a „Fourtune” felirat).
- `fourtune-logo-alairas.png` / `@3x.png` – a logó az aláírás méretében (211×62), az aláírás innen tölti be.
- `fourtune-logo.png` – az eredeti, kis felbontású logó (76×58), amiből a vektoros változat készült.
