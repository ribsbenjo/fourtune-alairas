# Fourtune e-mail aláírás

- `fourtune-alairas.html` – aláírás-készítő: nyisd meg böngészőben, írd át a nevet, szerepet, telefont és LinkedInt, majd **Aláírás másolása** és Cmd+V a levelező aláírás-mezőjébe.
- `fourtune-logo.svg` – a Fourtune logó vektorosan (bal oldalt a jel, jobbra a „Fourtune” felirat).
- `fourtune-logo-alairas.png` / `@3x.png` – a logó az aláírás méretében (211×62), Gmail-feltöltéshez.
- `fourtune-logo.png` – az eredeti, kis felbontású logó (76×58), amiből a vektoros változat készült.
